**앱 설명**: 걷는 동안 근처 장소를 찾아 AI가 오디오로 설명해 주는 여행 가이드입니다. 사용자가 "오른쪽 건물 뭐야?"처럼 물으면 현재 위치와 이동 방향을 기준으로 대상을 찾아 이야기로 답하고, 이어서 질문할 수 있습니다.

**검토 방법 (이탈리아 로마 등 현장에 없어도 확인 가능)**
1. 앱을 열고 하단 **"위치 시뮬레이터(데모)"** 를 누르세요. 로마 콜로세움 일대 지도에서 걷고 회전하며 질문해 볼 수 있습니다. 위치 권한 없이 동작합니다.
2. 실제 위치로 확인하려면 메인 화면에서 **"시작"** → 동의 화면 → 위치 권한 허용. 위키백과에 등록된 장소가 주변에 있으면 해설이 나옵니다(도심에서 가장 잘 동작).
3. "말로 질문"(마이크), "사진으로 물어보기"(카메라)는 눌렀을 때만 권한을 요청합니다.

**백그라운드 위치 사용 사유**
- 사용자가 직접 **"시작"**을 눌러 안내를 켠 동안에만 위치를 사용합니다. 이 기능의 핵심은 *주머니에 폰을 넣고 걸으며 이어폰으로 듣는* 사용 방식이어서, 화면이 잠겨도 가까운 장소에 다가가면 안내 음성이 나와야 합니다.
- Android: 위치를 쓰는 동안 **알림 표시줄에 지속 알림**("걷는 동안 주변 장소를 찾아 안내하고 있어요")이 표시되며, 사용자가 시작한 포그라운드 서비스로만 동작합니다(`ACCESS_BACKGROUND_LOCATION` 미사용).
- iOS: 위치 백그라운드 모드는 위 기능에만 쓰입니다. 위치 권한은 먼저 "앱 사용 중 허용"으로 요청하고, 위치 플러그인이 이후 "항상 허용"으로의 변경을 한 번 더 제안할 수 있습니다(거절해도 안내를 켠 상태의 백그라운드 동작은 유지됨 — *실기기에서 확인 후 이 문장을 확정할 것*). 앱의 **"■ 안내 종료"**로 언제든 중지됩니다. 광고·분석·추적 목적으로 쓰지 않습니다.
- 오디오 백그라운드 모드: 잠금화면/백그라운드에서도 안내 음성을 재생하기 위함입니다.

**AI 생성 콘텐츠**: 해설은 AI가 생성합니다. 앱 안의 모든 해설 아래 **"🚩 신고·오류 알리기"** 버튼으로 사실 오류/부적절한 내용을 신고할 수 있으며(서버에 저장되어 검토), 화면 하단에 AI 생성물 안내 문구가 있습니다.
