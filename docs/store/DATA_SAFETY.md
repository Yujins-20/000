# 스토어 개인정보 양식 응답 (앱의 실제 동작 기준)

앱이 바뀌면(분석 SDK 추가, 로그인, 결제 등) **반드시 다시 점검**한다. 근거: `web/privacy.html`, `ios/…/PrivacyInfo.xcprivacy`.

## Google Play — 데이터 보안(Data safety)
| 질문 | 응답 |
|---|---|
| 데이터 수집 여부 | 예 |
| 데이터 공유(제3자) 여부 | **아니요** (서비스 제공 처리자인 운영자 서버/중계 네트워크는 "공유"가 아님으로 설명 가능 — 정책 문구를 Play 정의에 맞춰 최종 확인) |
| 전송 중 암호화 | 예 (HTTPS) |
| 삭제 요청 방법 | 예 — 운영자 이메일로 요청 (계정이 없으므로 앱 내 삭제 기능 대신 문의 안내) |
| 수집 데이터 | **정확한 위치**(앱 기능, 선택적 아님·필수), **사진**(앱 기능, 선택: 카메라 질문 사용 시), **앱 활동/기타 사용자 생성 콘텐츠**(질문 텍스트·신고, 앱 기능), **음성/오디오는 수집하지 않음**(기기 음성 인식 결과 텍스트만 전송) |
| 데이터 보관 | 위치·질문·사진은 처리 후 저장하지 않음. 신고 내용만 보관 |
| 광고/분석 | 사용 안 함 |

추가 신고 사항:
- **AI 생성 콘텐츠 정책**: 앱 안 신고 기능 제공 ✅ (모든 해설 아래 버튼)
- **포그라운드 서비스(위치)**: 포그라운드 서비스 권한 선언 양식에 "사용자가 시작한 위치 안내(핵심 기능)" 설명, 시연 영상 요청 시 `docs/store/REVIEW_NOTES.md` 참고
- 타깃 연령: 일반(아동 대상 아님)

## Apple — App Privacy
| 데이터 유형 | 수집 | 사용자와 연결 | 추적 | 목적 |
|---|---|---|---|---|
| 정확한 위치 | 예 | 아니요 | 아니요 | 앱 기능 |
| 사진 또는 비디오 | 예 (카메라 질문 시) | 아니요 | 아니요 | 앱 기능 |
| 기타 사용자 콘텐츠(질문·신고) | 예 | 아니요 | 아니요 | 앱 기능 |
| 연락처/식별자/구매/사용 데이터/진단 | 아니요 | — | — | — |

- "데이터를 추적에 사용" → **아니요** (`NSPrivacyTracking=false`). App Tracking Transparency 불필요.
- 수출 규정: HTTPS 표준 암호만 사용 → `ITSAppUsesNonExemptEncryption=false` 이미 설정.
- 권한 문구는 `Info.plist`에 있으며 앱 안의 동의 화면과 같은 설명을 한다.
